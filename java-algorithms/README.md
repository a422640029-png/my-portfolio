## 📌 Projects & Implementations

### 🗓️ DayOfWeekCalculator.java
An original, 100% self-engineered algorithmic date calculator designed without using any external date/time libraries.

#### **Key Algorithmic Concepts:**
* **Dynamic Leap Year Calculations:** Handles dynamic February day allocations (28/29 days) based on standard leap year conditions.
* **Reverse Month-Iteration ($i$):** Uses a decrementing loop structure to process accumulated days accurately.
* **Modulo-7 Mathematical Mapping:** Employs a modulo-7 ($mod\ 7$) tracking formula relative to a fixed baseline reference date to determine the exact day of the week for any given input.
