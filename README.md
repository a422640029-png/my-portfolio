## 📂 Repository Contents & Projects

### 1. ☕ Advanced Java Software Development
* **Gaza Airport Management System:** A comprehensive, object-oriented (OOP) software application featuring a modular architecture with specialized domain classes (such as `airFlight`, `Pilot`, `flightAttendant`, and `travilar`) backed by a robust custom exception handling mechanism (`ExpiredPassportException`, `NoPilot`, `OverSeatsException`, etc.).

It features dynamic leap year tracking, reverse month-iteration loops ($i$), and a modulo-7 mathematical tracking model for precise day-of-the-week determination.

### 2. 🌐 Enterprise Computer Networking (CCNA Labs)
* **`ccna-networking/` & Simulation File (`finaly.pkt شبكات المشاريع`):** A fully validated multi-site enterprise network simulation built using Cisco Packet Tracer. 
* **Key Network Features:** 
  * Dynamic routing via **OSPF**.
  * VLAN segmentation and **Router-on-a-Stick (ROAS)**.
  * Automated IP address allocation through **DHCP Servers**.
  * Traffic filtering and security enforced via **Extended Access Control Lists (Extended ACL 105)**.
  * Local intranet web server hosting (`www.medicare.local`).
